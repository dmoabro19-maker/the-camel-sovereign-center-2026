THE CAMEL — Project Blueprint

1. Mission

Build THE CAMEL Sovereign Command Center: an owner-governed Bitcoin rewards and earning platform.

2. Core Intelligence

THE CAMEL is the central intelligence coordinating three specialist bots.

- DUNE: ZBD gaming and referral operations.
- SIROCCO: Independent earning research and opportunities.
- OASIS: Bitcoin rewards Treasury and payout administration.

3. Two Earning Humps

1. ZBD-based earning and rewards.
2. Independent earning opportunities managed through THE CAMEL.

Kalshi intelligence, if enabled, remains separate from Bitcoin rewards accounting.

4. Public Command Center

The public-facing application will provide:

- Dashboard and activity overview.
- Earning and rewards tracking.
- Specialist bot status.
- Treasury summaries.
- Notifications and reports.

5. Private Moderator — God Mode

The private owner-only control center will provide:

- System-wide oversight.
- Bot permissions and controls.
- Security settings.
- Audit history.
- Emergency pause controls.
- Owner approval for sensitive actions.

6. Owner Supremacy

The owner retains final authority. No bot may independently authorize financial transfers, withdrawals, trades, or other sensitive financial actions.

7. Security

- Protect private credentials and API keys.
- Never expose secrets in public files.
- Require authorization for private controls.
- Record important system actions.
- Keep public and private functions separate.

8. Development Roadmap

1. Establish repository and documentation.
2. Build the project structure.
3. Develop the public dashboard.
4. Develop the private Moderator interface.
5. Implement specialist bot architecture.
6. Research and connect approved integrations.
7. Test security and permissions.
8. Deploy only after owner approval.

9. Important Development Rule

All earning figures, reward rates, and automation capabilities must be verified before being treated as operational facts. Prototypes are not live integrations.

THE CAMEL — Owner governed. Security first. Bitcoin rewards focused.
